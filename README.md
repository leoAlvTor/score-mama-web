# Score MAMÁ Web

Sitio público e independiente para presentar la aplicación Score MAMÁ 2025.

## Seguridad del repositorio

Este proyecto contiene únicamente archivos estáticos y capturas promocionales. No contiene código fuente, bases de datos, documentos clínicos internos, credenciales ni configuraciones de la aplicación móvil.

## Desarrollo local

```bash
python3 -m http.server 8080
```

Abrir `http://localhost:8080`.

## App Store

Cuando exista la URL pública, reemplazar el bloque `store-placeholder` de `index.html` por un enlace directo al producto.
